# 🔄 НМГ (CGM) - Быстрая справка

## Что это?
**НМГ (Непрерывный Мониторинг Глюкозы)** / **CGM (Continuous Glucose Monitoring)** - функциональность для работы с датчиками непрерывного мониторинга глюкозы.

## 🎯 Где находится код?

### Основной файл с логикой:
```
presentation/src/main/java/com/elta/android/presentation/features/sync/connect/viewmodel/ConnectingViewModel.kt
```

### Другие важные файлы:
- `domain/.../devices/interactor/ManageCgmMonitoringUseCase.kt` - управление мониторингом
- `domain/.../devices/interactor/SyncWithCgmUseCase.kt` - синхронизация данных
- `data/.../devices/cgm/service/CgmMonitoringService.kt` - фоновый сервис
- `data/.../devices/cgm/manager/CgmManager.kt` - менеджер подключений

## ⚡ Быстрое управление

### Отключить НМГ:
```bash
./toggle_nmg.sh disable
```

### Включить НМГ:
```bash
./toggle_nmg.sh enable
```

### Восстановить из резервной копии:
```bash
./toggle_nmg.sh restore
```

## 🔍 Поиск НМГ кода

Все блоки НМГ логики помечены специальными комментариями:

```kotlin
// ========== НМГ: НАЧАЛО ==========
// НМГ код здесь
// ========== НМГ: КОНЕЦ ==========
```

## 📦 Что включает НМГ?

1. **Импорты UseCase** (2 штуки)
2. **Параметры конструктора** (2 параметра)
3. **Логика синхронизации** в `syncDevice()` (~70 строк)
4. **Логика выхода** в `exitFromScreen()` (~10 строк)
5. **Комментарий** в `completeConnect()` (2 строки)

## ⚠️ Важно!

- **Не удаляйте** блочные комментарии `// ========== НМГ: ... ==========`
- Они нужны для работы скрипта и быстрой навигации
- При закомментировании сохраняются все маркеры

## 🧪 Тестирование
