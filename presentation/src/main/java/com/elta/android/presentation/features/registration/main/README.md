# Регистрация на Compose

`ui/RegistrationScreen.kt` — внешний вид, форма, согласие и четыре Preview.
`model/RegistrationState.kt` — состояние и действия. Для отправки нужны валидные
email и пароль, явное согласие и отсутствие выполняющегося запроса.

Экран использует общий `AuthScreenLayout`, поля и кнопку из авторизации.
Тексты берутся из конфигурации `registration-screens`, иллюстрация — локальная `img_registration`.
Компактный размер 125×120 dp выбран для этой основы по аналогии с восстановлением;
это не подтверждённый размер отдельного макета регистрации. Меняется параметром
`compactIllustrationSize` в `RegistrationScreen`.

`ui/BaseRegistrationComposeFragment.kt` показывает состояние `RegistrationViewModel`
и открывает документы или сообщение по разовым эффектам. Оба маршрута,
`RegistrationMain` и `RegistrationMainVariantA`, используют одну ViewModel и экран.
`RegistrationSession` отправляет запрос с языком и страной; `RegistrationTelemetry`
отправляет события. ViewModel управляет формой, переходами и ошибками. В обычном
варианте удалённый профиль даёт ошибку формы, в старом — диалог с поддержкой.

Согласие хранится в ViewModel и не сбрасывается при пересоздании View. Обе ссылки
в тексте открывают существующий экран документов.
`RegistrationConsentText.kt` убирает жёсткие переносы для естественного переноса
текста на разных экранах; слова и адреса документов сохраняются.
