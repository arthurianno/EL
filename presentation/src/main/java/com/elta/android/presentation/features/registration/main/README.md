# Регистрация на Compose

`ui/RegistrationScreen.kt` — внешний вид, форма, согласие и четыре Preview.
`model/RegistrationState.kt` — состояние и действия. Для отправки нужны валидные
email и пароль, явное согласие и отсутствие выполняющегося запроса.

Экран использует общий `AuthScreenLayout`, поля и кнопку из авторизации.
Иллюстрация берётся из конфигурации `registration-screens`, запасная — `ic_welcome`.
Компактный размер 125×120 dp выбран для этой основы по аналогии с восстановлением;
это не подтверждённый размер отдельного макета регистрации. Меняется параметром
`compactIllustrationSize` в `RegistrationScreen`.

`ui/BaseRegistrationComposeFragment.kt` связывает UI с RxPM: ввод, согласие,
загрузка, конфигурация, серверные ошибки и навигация. Оба существующих маршрута
`RegistrationMain` и `RegistrationMainVariantA` уже используют новый экран.
Запрос регистрации, параметры языка/страны, аналитика, переход на активацию и
обработка удалённого аккаунта остаются в существующих PM.

Согласие хранится в PM и не сбрасывается при пересоздании View. Обе ссылки в тексте
вызывают прежние действия PM и открывают существующий экран документов.
`RegistrationConsentText.kt` убирает жёсткие переносы для естественного переноса
текста на разных экранах; слова и адреса документов сохраняются.
