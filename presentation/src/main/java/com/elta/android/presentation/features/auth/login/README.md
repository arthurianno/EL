# Основа экрана входа

`ui/LoginScreen.kt` — Compose UI с четырьмя Preview: пустая форма, заполненная,
ошибки на маленьком экране с увеличенным шрифтом и загрузка. Здесь меняются поля,
отступы формы, кнопка и иллюстрация. Используется локальная `img_login`.

`model/LoginState.kt` — состояние и действия формы. Доступность кнопки использует
существующие проверки email и пароля из domain. Экран получает состояние снаружи,
передаёт ввод через `onAction`, а переходы — через `onBack` и `onForgotPassword`.

`../ui/AuthScreenLayout.kt` — общая компоновка для похожих экранов: верхняя панель,
заголовок, описание, иллюстрация и слот формы. Она учитывает системные панели и IME.
Её используют также восстановление и создание пароля. Сначала измеряются заголовок
и форма, затем картинка уменьшается до оставшегося места с сохранением пропорций.
Форма прижата вниз, пока хватает высоты; при переполнении весь контент под верхней
панелью прокручивается, включая форму и кнопку.

Параметр `compactIllustrationSize` задаётся на каждом экране: вход — 155×149 dp,
восстановление — 125×120 dp, новый пароль — 183×176 dp. Без клавиатуры максимальный
размер — 375×360 dp. Это ориентиры из Figma; доступная ширина и измеренная высота
контента могут дополнительно уменьшить картинку. Минимальная высота 72 dp — правило
адаптации приложения, не значение Figma; при меньшем остатке высоты включается скролл.
Переключение размера анимируется за 200 мс. Повторно добавлять системные отступы
во Fragment при подключении этой компоновки не нужно.

Экран подключён к обоим существующим маршрутам: `Screens.Login` и
`Screens.LoginVariantA`. Их Fragment используют общие `LoginViewModel` и `LoginSession`.
ViewModel хранит состояние формы и диалогов; Session выполняет вход и восстановление,
`LoginPostAuth` подготавливает профиль и выбирает следующий экран, а `LoginTelemetry`
содержит события аналитики. В новом варианте доступно восстановление удалённого профиля;
старый вариант предлагает написать в поддержку. Кнопки «Назад» и «Забыли пароль?»
ведут в прежние маршруты; системный Back совпадает с кнопкой «Назад».
Загрузка отображается в кнопке, серверная ошибка — под полями. Тексты нового
варианта берутся из конфигурации `login-screen`, иллюстрация локальная.
